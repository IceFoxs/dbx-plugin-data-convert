# 2026-10-26

### 导航栏可切到左侧（默认顶部 + 跨会话记忆）

需求三连：「增加导航栏切换功能，可以切到左侧，其他功能不要变」→「默认顶部导航栏」→「支持导航栏切换记忆」→「再次打开要为最后一次的模式」→「考虑对dbx插件的记忆」。

**实现**
- 顶栏最右加 `#navToggle`（32×32 图标按钮，`data-keep-title`），图标随布局切换：顶部显示"顶栏"图、左侧显示"侧栏"图。
- `body.nav-left` 下 `#navLinks` 变 `position: fixed; top: 3.5rem; left: 0; width: 13rem` 竖排 + 纵向滚动，`.main-container` 让出同宽，`#navMore` 隐藏，`.nav-convert { margin-right: auto }` 把语言/切换顶右。规则全部包在 `@media (min-width: 769px)`，窄屏只保留顶部（`.nav-toggle { display: none }`）。
- i18n：`NAV_I18N` 14 语各加 `navToggleToLeft` / `navToggleToTop`，新增 `navT()`（主字典没有这些键）。切语言时 `applyI18n` 调 `navSyncToggleLabel()`。
- `layoutNav()` 加短路：`nav-left` 且 `innerWidth > 768` 直接返回，不把项搬进被隐藏的「更多」。

**持久化（关键决策）**
- 查官方文档确认：DBX 工作台是 **opaque origin 沙箱，`localStorage` 会抛 SecurityError**，官方明确要求用 `window.dbxPlugin.storage`，需 `host.storage` 权限 + `capabilities.storage` 门控。
- manifest `permissions` 加 `host.storage`。
- 三级降级：宿主 storage → 浏览器 localStorage（dev/预览）→ 内存。键 `navLayout` = `top` / `left`。启动先同步 localStorage 预读（避免闪一下顶部），再 `await dbxPlugin.ready` 后 `storage.get('navLayout')` 校正。
- `set` 失败静默，不打扰用户。

**踩坑**
- **1440 宽下 10 个导航项变 8 个**：新按钮占 32px + gap，导致「更多」出现并再占 80px。实测 `.nav-links a` padding 从 `0.8rem` 收到 `0.65rem` 后 10 项全回来（navW 861 → 948）。左侧栏项单独 padding 不受影响。
- 左侧栏宽度用 `--nav-left-w: 13rem` 变量统一（`#navLinks` 宽 + `main-container` margin-left）。

**验证**
- 真 Chrome 1440×900：顶部 10 项 / more=false；左侧 nav(0,56,208,844)、main left=208；刷新后仍是左侧（stored=left）；切回顶部 stored=top；控制台无报错。
- `ui.smoke.js` 233 → **236**（新增 3 条：默认顶部、切左侧 10 项不出现「更多」、再点回顶部）。
- `i18n.test.js` 52 通过。
- 11 张 README 截图整套重拍（1440×900、亮色、无 toast、顶部布局），逐张确认非空态；与中英 README 引用双向一致。
