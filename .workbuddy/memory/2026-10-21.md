## 结构化差异（Convert 页对比视图）

- 需求：对比时不要「整块标红/标绿」，而是只标出真正变了的**值**，并列出变更清单。
- 新增 `ui/js/objdiff.js`（纯函数，UMD）：
  - `diffObjects(a, b)` → `{changes:[{pointer,type:'change'|'add'|'remove',from,to}], stats}`，路径用 JSON Pointer（`/products/0/price`）。
  - `serializeTracked(obj)` → 按 `JSON.stringify(obj,null,2)` 打印并记录每个节点的 `{line,col,endLine,endCol}`；打印与定位同源，行号不会错位。
  - `displayValue()` 面板值格式化。
- 转换页对比视图：两侧都是 JSON 时用 `serializeTracked` 渲染 + 只对变更值打 `cm-diff-old/new` 内联标记（行底色 `cm-value-changed`）；右下角浮层「结构化差异 N 处」按路径列出，点击两侧同步滚动。跨格式只给清单、不涂色（整块涂色在跨格式下毫无意义）。非 JSON 且解析失败时回退行级 diff。
- 用例：`tests/objdiff.test.js` 16 条 → 后增至 22 条；`tests/ui.smoke.js` 增加 4 项（清单条数/只标变更行/精确标记/无差异提示）。

## 导航栏溢出 → 「更多」下拉

- 需求：导航项多的时候收进「更多」，出现横向滚动条时也改成「更多」。
- 做法：`.nav-links` 从 `overflow-x: auto` 改成 `overflow: hidden`（去掉滚动条与 `::-webkit-scrollbar` 美化样式），末尾追加 `#navMore`（`nav-more-trigger` + `nav-more-menu`）。
- 核心 `layoutNav()`：先用 `data-nav-idx` 把项按原始顺序全部 append 回 `#navLinks`，再用 `scrollWidth - clientWidth > 1` 判断溢出；放得下就不显示「更多」，放不下就显示按钮并从末尾往前逐项 `insertBefore` 到菜单首位（顺序不变、项数守恒）。`.nav-compare`（JSON 对比）作为固定项最后才收。极端窄屏全部收起时给 `#navLinks` 加 `is-empty`（`flex: 0 0 0`）避免品牌和「更多」之间留空档。
- 触发时机：初始化（`applyI18n()` 末尾会调一次，因为文案长度随语言变）、`resize`（80ms 防抖）、`load`、`document.fonts.ready`。
- 交互：点触发器 toggle（`aria-expanded` 同步）、点页面空白或 Esc 关闭、选中项自动收起。
- 关键重构：导航点击从「逐个 addEventListener」改成 `.topbar` 上的事件委托（`closest('#navLinks a, #navMoreMenu a')`），否则被搬进菜单的项会丢事件。原 `const navLinks = querySelectorAll(...)` 已删除。
- i18n：新增 `navMore`，14 套字典全补（More / その他 / 더보기 / Ещё …）。
- 实测（真实 Chrome）：8 项在 ≥1180px 全直出、无溢出；1000/860/720/560px 分别 5+3 / 4+4 / 3+5 / 2+6，全部 `overflow = 0`、`JSON 对比` 始终在条上；430px 全收进菜单且 `is-empty` 生效；切英文后重新布局不溢出；模拟再加 6 项（共 14 项）自动收 10 项、顺序正确、从菜单点项仍能切格式。
- 用例：`tests/ui.smoke.js` 增至 **40** 项（用 `Object.defineProperty` stub `scrollWidth/clientWidth` 模拟溢出，校验项数守恒、前缀/后缀顺序、菜单点击、复原）。
- 文档：CHANGELOG 0.1.3 补一条；README 中英补特性与 `docs/screen-nav-more.png`；另存 `docs/screen-nav-more-dark.png`、`docs/screen-nav-more-mobile.png`；重新打包 0.1.3。

## 任意文本模式：去掉删除线（可读性）

- 用户截图反馈：把 JSON 贴进「任意文本」后，差异行被 `line-through` + `opacity: .72` 划掉，文字几乎看不清（箭头指着被划的 `"list": [],`）。
- 修复：`.cm-text-del` / `.cm-text-ins` 改成对称的「行首 2px 色条」（`box-shadow: inset 2px 0 0`，左红右绿，暗色用 `#f87171` / `#4ade80`），底色仍由 `.cm-deleted` / `.cm-inserted` 提供；**不再划线、不再压暗文字**，贴代码/JSON 也逐行可读。
- 附带的贴心提示：文本模式下若两侧都能 `JSON.parse`，在「共有 N 行不同」后追加 `· 两侧都是 JSON，切到「JSON 对比」可精确到字段`（i18n key `cmpTipUseJson`，14 套字典）。
- 用例：ui.smoke 增至 **41** 项（新增「文本模式遇到 JSON 内容会建议切回 JSON 对比」）；浏览器侧 `text-readability.js` 复现截图场景，断言 `text-decoration: none`、`opacity: 1`、左右色条存在、提示含 JSON 建议，暗色同样通过。
- 截图：`docs/screen-text-mode-json.png`、`screen-text-mode-json-dark.png`；`screen-compare-text.png` 已用新样式重拍；CHANGELOG / README 中英文描述由「删除线」改为「行首色条」；重新打包 0.1.3。
