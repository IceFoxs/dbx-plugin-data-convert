# 2026-10-29

## SQL 分析页：全流程复验 + 界面收尾

### 引擎（`ui/js/sqlrun.js`）
- **`HAVING` 里用 SELECT 别名 / 聚合**：原本 `havingFn` 走 `predicateGroup → groupExpr`，`resolve()` 只认表列，`HAVING n > 1` 直接报「没有这一列 n」。
  - 做法：`substituteAliases()` 把命中输出列名的 `col` 节点换成 `{ k:'val', fn }`；`groupExpr` 增加 `case 'val'` 直接调 `node.fn`。
  - **坑一**：克隆节点会让 `aggSlot.get()` 取不到（累加器槽位按节点身份登记），`HAVING SUM(b) > 4` 恒为假 → 聚合调用整个原样返回，其余节点「没变就不克隆」。
  - **坑二**：`aliasValueNode` 一开始按 `isAggQuery` 走 `rowExpr`，而 HAVING 只在分组路径求值 → 一律用 `groupExpr`。
- 测试 151 → **203**：`DISTINCT` 组 + `HAVING` 三种写法 + **27 个关键字 / 18 个函数覆盖表**（`KEYWORD_CASES` / `FUNCTION_CASES`，加关键字就往表里加一行）。

### 交互（`ui/js/app/19-datasql.js`）
- **点「运行」= 跑整段**：原来没选区只跑光标那条，用户的批量语句被悄悄跳过。`dataSqlRun` 现在是「入参 sql → 选区 → `opts.statement`（右键『执行当前语句』）→ 整段」，批量才跑得起来。
- **页签只切 class**：`dataSqlSelectBatch` 原本调 `dataSqlRenderBatchTabs()` 重画 innerHTML，手上的按钮成游离节点 → 连点第二次没反应、焦点也丢。新增 `dataSqlSyncBatchTabs()`。
- **失败页签的空态文案**：`dataSqlEmptyHint('error')` 换掉「贴一段表格数据，写一句 SQL」（有 `data-i18n` 属性会被 applyI18n 重置，先摘属性）；新键 `dataSqlBatchTabFail` 14 语。
- **进度条 100% 后 0.9 s 自己收**（`dataSqlProgressHideTimer`）。
- **首屏 i18n 漏扫**：`DATASQL_I18N` 在 `18-flow.js` 末尾那次 `applyI18n()` 之后才定义 → 本页 placeholder / title 首屏全空，切一次语言才齐全。文件末尾补一次 `applyI18n()`；切语言时另外 `setOption('placeholder', …)` 同步给 CodeMirror（它只在建编辑器那一刻取一次）。

### 样式（`ui/css/app.css`）
- **暗色下 SQL 编辑区是白底**：`var(--surface, #fff)` 里的 `--surface` / `--surface-muted` **从来没定义过**，fallback 永远取白。现在亮 / 暗两套令牌都定义（优先跟随宿主 `--color-card`），列类型面板与右键菜单一起修好。
- `.pane-badge:empty { display: none }`：空徽标原本画成一颗灰胶囊，看着像「—」。
- 右键菜单：0.78rem → 0.8125rem、宽度 11.5rem、内边距放宽。
