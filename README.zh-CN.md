# 数据转换 (Data Format Converter)

一个 [DBX](https://dbxio.com) 插件，把数据在工作台里转来转去：JSON / YAML / XML / Properties / TOML / INI / `.env` / CSV / TSV / Query / Headers / Cookie / HTML 共 13 种格式互转、按字段对比、批量值生成 SQL、Excel / CSV 转 JSON、图片 ⇄ Base64、JSON / `CREATE TABLE` 直接生成多语言模型代码，外加 JSONPath / jq 查询、JSON Schema 校验、一组转义工具、字节换算（1000 / 1024 两套进制）、时间戳与日期互转（本地 / UTC / ISO 8601 / 相对时间，批量），以及把 JSON 直接画成 ECharts 图表并导出 PNG / SVG，还有二维码的生成与识别（批量生成，或把图片解回文本）。采用 **纯前端（通用）** 模板构建——单个跨平台 `.dbxp`，没有原生后端、不联网、可离线运行。

## 格式转换

- **源格式 × 目标格式两个选择器**，13 × 13 随便配：结构化一组（JSON / YAML / XML / Properties / TOML / INI / `.env`），表格与文本一组（CSV / TSV / Query / Headers / Cookie / HTML），下拉里分组列出、超高内部滚动。
- **TOML**：表头 `[db]`、数组表 `[[items]]`、inline table、dotted key、三引号多行字符串、十六进制 / 八进制 / 二进制 / 下划线数字、`inf` / `nan`、日期时间（按字符串往返）都认；重复定义同一张表会报出「第几行」。
- **INI / `.env`**：`[section]` 平级（不会嵌进上一节）、`export` 前缀、引号内的转义、`#` 注释都在行尾也能认；`.env` 的嵌套键拍平成 `db.host`。
- **CSV / TSV**：JSON 数组 → 表格，嵌套对象自动拍平成 `address.city`、数组变成 `tags[0]` / `tags[1]`；反向读回来会还原成嵌套结构与数字 / 布尔类型。空格子不写键，CSV 区分不了 `null` 和空串。
- **Query / Headers / Cookie**：抓包粘一段就变结构化——Query 的重复键变数组（`a=1&a=2` → `["1","2"]`）、Headers 跳过请求行与状态行、Cookie 里 `HttpOnly` 这类裸标记记成 `true`。
- **HTML**：对象数组 ⇄ `<table>`（含 `<thead>` / `<tbody>`、HTML 转义），没有 `<th>` 时自动生成列名。
- JSON / YAML / XML 自动美化、校验失败能指出问题所在，另有模拟数据生成器，做 Schema 试跑不用手写样本。
- 输入输出都有行号与语法着色：TOML / `.env`（shell）/ Headers（HTTP）/ INI（properties）各有自己的配色，切格式即换。
- 全部本地完成：贴进去就转，不请求网络。

## 对比

- **结构化 JSON 对比**——两侧先解析成对象树，按 JSON Pointer 逐节点比，只高亮真正变了的那个值，并在右下角列出变更清单（修改 / 新增 / 删除 + 路径 + 新值），点任意一行两侧同时滚到对应位置；跨格式（json ↔ yaml）只给清单，不做无意义的整块涂色。
- **任意文本对比**——Markdown、配置文件、HTML 片段、日志：按行比对，删掉的行淡红底 + 行首红条，新增的行淡绿底 + 行首绿条，不划删除线，代码也读得清；两侧都是合法 JSON 时会提示改用 JSON 对比。
- 每种模式自带 4 组示例，不准备数据也能直接试。
- **两栏各自导入**：顶栏的「导入左侧」「导入右侧」分别往对应那一栏读文件，读哪个都不影响另一栏；直接把文件拖进窗口时，先填还空着的那一侧。

## SQL 转换

- 左边一行一个值（逗号、分号、制表符也认），右边直接出 SQL：`IN (...)`、`NOT IN (...)`、值列表、`INSERT INTO ... VALUES ...;`，多行或单行随时切。
- 引号可选：单引号 / 双引号 / 不加引号。纯数字默认加引号（`'31010100003922409'`，ID 列大多是 varchar），勾上「数字不加引号」才输出裸数字，避免 int 列隐式转换丢索引。
- 从 SQL 文件里整段粘回来的 `WHERE id IN ('a','b')`、`INSERT ... VALUES ('a'),('b')` 也能反向拆出干净的值；成对引号还原、`O'Brien` 不会被拆坏、重复值自动去掉并分别显示「拆出几个 / 用了几个」。
- 输入即生成，`Cmd/Ctrl+Enter` 立即出结果，一键复制。

## 表格转 JSON

- 拖入 `.xlsx` / `.csv` / `.tsv`：首行作表头（可关），分隔符自动嗅探（也能钉住 `,` / Tab / `;`），数字与布尔可推断，但 `007`、超过 15 位的长编号始终按字符串处理；短行补空、重名列加 `_2`。
- Excel 日期还原成 `2024-03-01`（内置与自定义 `numFmt` 都认），共享字符串 / `inlineStr` / 布尔 / `#DIV/0!` 之类错误值照原样还原，ZIP64 写出来的 xlsx 也能读。
- 旁边是实时预览表格：列多时按内容撑开、底部常驻横向滚动条，单元格被截断时双击弹出详情（完整内容 + 整行所有列）。
- 输出可切 **JSON**（逐字段缩进 / 一条记录一行）或 **SQL Insert**（表名可改、每 500 条一句、单引号转义、导出 `.sql`），「最多条数」只转前 N 条。
- 大文件不假死：单文件 20 MB / 10 万行上限，预览只画 500 行，序列化分批让出主线程并显示进度，切文件时旧任务作废；导出走宿主 `fileTransfer`，没有宿主才回退浏览器下载。

## 图片 ⇄ Base64

- **编码**：选文件、拖进来或 `Ctrl/Cmd+V` 粘贴截图，输出 DataURI、纯 Base64、CSS、HTML、Markdown——切换格式不用重新编码。
- **解码**：边贴边出图（300 ms 防抖），尺寸、体积、字符数、+33% 膨胀率都摆在图下面，棋盘格底让透明 PNG 不会糊在白底上。
- **导入文件，导出都兜得回来**：解码页的「导入文件」直接读 `.txt` / `.b64` / `.json`（也可以把文件拖进来），编码页导出的 `.txt` / `.base64.txt`、连同 CSS / HTML / Markdown 三种包装都能读回来还原成图片。导入只认本页那一类：在这一页选到图片只会提示去「图片转 Base64」，页面不会被换走。文本文件上限 16 MB，二进制文件在入口拦下。
- **纯 Base64 与 DataURI 等价**：没有 `data:` 前缀的裸串同样能解，类型靠魔数嗅探（PNG / JPEG / GIF / BMP / WEBP / ICO / AVIF / HEIC / SVG），提示里写明读到的是哪一种。现实变体先规范化再校验：76 字符换行、url-safe `-_`、缺补位、引号 / `url("…")` / 整条 CSS 声明、只抄了 `image/png;base64,` 半截前缀、UTF-8 BOM。在编码页 `Ctrl/Cmd+V` 粘贴一段 Base64 会自动切到解码页。页面不设「读剪贴板」按钮——macOS 的 WebView 会在按钮旁边弹一个自己的 Paste 气泡，所以贴图一律走 `Ctrl/Cmd+V` 或拖拽（两条路都拿得到完整图片数据）。
- **SVG 也算图片**：`.svg` 编码成 `image/svg+xml`，SVG 的 Base64 / DataURI 能解回图片；矢量图本来就是文本，所以**SVG 源码**也能直接贴进来，自动按 UTF-8 编码再渲染。嗅探会跳过 BOM、`<?xml?>`、`<!DOCTYPE svg>` 和注释，HTML 里恰好嵌了个 `<svg>` 不会被误判。
- **内存有界，不拖垮宿主**：单张图 10 MB、Base64 文本 14 M 字符，超了在入口拦下。编码按 3 字节对齐分块，带进度条与取消 token（8 MB 约 250 ms）。预览最多 200 K 字符，Base64 超过 2 M 字符时整串**不留在内存里**——预览由切片拼出，导出时才拼一次；预览图走 object URL 而不是几 MB 的 data URI，截断时点「复制」会引导去导出文件而不是假装成功。

## 代码生成

- 左边贴一段 **JSON 示例**，右边立刻出模型：嵌套对象与对象数组自动拆成独立类型（依赖先于使用者输出），同名结构合并、只有部分样本出现的字段自动变可选。
- 也可以切到 **SQL DDL**：粘一条 `CREATE TABLE`（MySQL 反引号、PostgreSQL 双引号 / `serial` 都认），直接出对应模型。列名转小驼峰、表注释与列注释带进代码、`t_` / `tb_` 这类表名前缀不进类型名、主键与索引约束不会变成字段；多条 `CREATE TABLE` 一次出多个类型。
- 四种语言随时切：**TypeScript** 接口、**Go** struct（带 `json` tag 与 `omitempty`）、**Java** POJO（包装类型 + getter/setter）、**Python** dataclass（snake_case + `Optional`）。切换不用重新输入。
- 根类型名可以自己填，留空就按输入自动命名；填了脏字符串（含空格、数字开头、中文）也会清洗成合法标识符，不会生成编译不过的代码。
- 纯前端推断，不联网、不 `eval`；输入超过 1 M 字符、超大数组、超深嵌套都会在入口降级或拦下，不会把宿主卡死。
- 输入输出都是真正的编辑器（CodeMirror）：行号、语法着色、括号自动配对、代码折叠、当前行高亮。输入按源格式上色（JSON / SQL DDL），输出跟着目标语言走（TypeScript / Go / Java / Python），切页签即换配色；`⌘ / Ctrl + Enter` 就地重跑。

## 查询校验

- **两种方言共用一套解析器**——贴上文档、写个路径就行。JSONPath（`$`、`.key`、`['key']`、`[0]`、`[*]`、`..` 递归下降、`[start:end:step]` 切片、`[?(@.price < 10 && @.cat == "fiction")]` 过滤器，支持 `=~` 正则）和 jq 子集（`|` 管道、`,` 并集、`[]` 迭代）都认，按写法自动判断你用的是哪一种，不用选。
- **结果能接着用**——只命中一个就直接输出那个值，命中多个输出 JSON 数组并标出条数。结果下方是**匹配路径列表**（最多 200 行，以 `$` 开头），点一行即复制该路径，查询结果顺手就能变成 JSON Pointer 或代码里的常量。
- **JSON Schema 校验**——draft-07 子集：`type` / `enum` / `const` / `format`，字符串（`minLength`、`pattern` 等）、数字、对象（`properties`、`required`、`additionalProperties`、`patternProperties`）、数组（`items`、`contains`、`uniqueItems`、`minItems` 等）、`allOf` / `anyOf` / `oneOf` / `not`、`if` / `then` / `else`，以及本地 `$ref`（`#/definitions/…`，带访问栈，自引用 Schema 不会爆栈）。
- **报错是给人读的**——每条错误都带实例路径、一句本地化说明和一个固定错误码（`schema-type`、`schema-required` 等），最多列 200 条，写错的 Schema 也能立刻给答复。
- **反推 Schema**——一键把手上这段数据变成起点：类型推断好、`required` 补齐、邮箱 / 日期 / UUID 猜出 `format`、数组元素跨项合并。
- 和别处一样有上限：输入 2 M 字符、结果 1 000 个节点、访问 200 000 个节点，超了就标「已截断」，不会把宿主拖住。

## 转义工具

- 一页八种：**URL**、**Base64**、**HTML**、**JSON 字符串**、**`\uXXXX`**、**Hex**、**SQL 字面量**、**正则**，编码 / 解码两档，**对调**按钮一次把两个面板和方向一起换过去，随手就能做一次往返验证。
- **和其它页面一样的独立页**：从导航进入后一直留着，不会自己收起，长时间来回转义也不和工作台里别的页面抢位置；导航像别的页一样高亮，转换 / 对比 / SQL 页在它开着时不受影响。
- **JSON 字符串是一等公民**，不是格式转换的副产物：编码后是完整的 JSON 字面量，`"`、`\`、换行、制表符、控制字符（`\u0007` 这类）都会正确转义，中文保持可读而不是全变成 `\uXXXX`——要那个效果请用 **Unicode** 一档。解码时带外层引号的完整字面量和裸的转义片段都认，后者才是从日志里复制出来的常见样子。
- **按字节算，不是 Latin-1**——Base64 与 Hex 走手写的 UTF-8 编解码而不是 `btoa`，`中文` 出来是 `5Lit5paH` 而不是乱码，解回来逐字节一致，代理对也不丢。
- **HTML / SQL / 正则**只转义该转的、绝不重复转义（`O'Brien` → `O''Brien`，`[a-z]{2}` → `\[a-z\]\{2\}`），反向解码则保留其它种类的转义。
- 输入不合法会回错误码（Base64 长度不对、`\u` 后面不是四位十六进制等），不会闷头吐出一串垃圾；超过 2 M 字符在入口拦下。

## 字节转换

- **单位换算，两套进制分开列**：B / KB / MB / GB / TB / PB 走 1000 进制，B / KiB / MiB / GiB / TiB / PiB 走 1024 进制，同一行并排显示，不会把 1.5 MB 和 1.5 MiB 当成一个数。小数位 0–6 随时切。
- **两种写法互转**：输入 `1234567890` 出 `1.23 GB` 与 `1.15 GiB`；反过来贴 `1.15 GiB` 也能算出 `1234567890` 字节。带单位、纯数字、`700M` 这类简写都认，大小写不敏感。
- **批量**：一行一条，`1234567890` / `1.5 GB` / `734003200` 混着贴，逐行给出两套换算并在末尾汇总合计——把一堆文件大小粘进来直接求和是常用姿势；某一行看不懂只标那一行，不影响其它行。复制出来是 TSV，粘进 Excel 正好是四列。
- **字节的其它写法**：贴一段字节序列（`1f 8b 08`、`1f8b08`、`[0x1f, 0x8b]`、`0x1f 0x8b`、二进制 `00011111 10001011`，或整段 `xxd` 输出）就能拿到 **Hex dump**（xxd 风格，带偏移与 ASCII 列）、**字节数组**、**二进制串**三种形式，各自可复制。和「转义工具」里的 Hex 分工不同：那边转的是字符串编码，这边是数值与字节表示。
- **每个值单独可复制**：三张汇总卡（精确值 / 1000 进制 / 1024 进制）各有自己的「复制」，表格里每个换算结果点一下就进剪贴板；复制出来只有数字或「数字 + 单位」，**不带千分位逗号**，可以直接贴进代码、命令行或配置文件。整体复制仍是那个 TSV。
- 认不出的输入只报错不猜（`zzz` 不会被当成十六进制）；单行序列上限 8 KB、单条数值上限 1 EiB 量级，超出就说明上限，不会让页面卡住。

## 时间转换

- **快捷操作直接填**：顶部一排按钮——当前时间、今天开始、昨天、本周开始、本月开始，点一下就把对应时刻**换行追加**到输入框末尾并立刻转换（「昨天」是昨天 00:00:00，「本周开始」按周一算）。时间一律截到整秒，填进去的就是 `2026-10-25 00:00:00` 这种本页能解析的写法，不用记格式。
- **一行一个时间，混着贴也行**：`2020-01-01`、`2020-01-01 00:00:00`、`2020-01-01T00:00:00`、`1577836800`、`1577836800000` 各占一行粘进来，逐行给出该行对应的各种写法；某一行看不懂只标那一行，其余照转，不会整批失败。
- **只转你要的格式**：规则条上七个勾选项——Unix 时间戳（秒）、Unix 时间戳（毫秒）、本地时间、本地时间（T）、UTC 时间、ISO 8601、相对时间。默认只勾「本地时间」和「本地时间（T）」，也就是 `2020-01-01 00:00:00` ⇄ `2020-01-01T00:00:00` 这种最常用的互换；多勾一个，结果卡片里就多一栏。
- **结果可折叠**：每条输入一张卡片，标题上是行号与原值，点标题收起 / 展开（`−` / `+`），贴几十行也不会滚到手软。
- **光标停在哪行，就定位到哪条**：输入框里把光标挪到第 N 行，右边自动滚到第 N 张卡片并高亮一下，不用自己数着找。
- **复制只有结果**：每个值点一下就进剪贴板（悬停是复制光标），「复制整行」给一行 TSV；「复制」按钮按「每行输入一行、勾选的字段用空格连接、行间换行」输出，不带序号、不带输入原值、不带字段名，直接贴进表格或代码。相对时间只是给人看的（「3 年前」这类），不进批量复制。
- 时间戳按位数认（10 位秒 / 13 位毫秒 / 16 位微秒裁到毫秒），带 `Z` 或 `+08:00` 的 ISO 也认；一次最多 2000 行，超出会说明截断。

## JSON 转图表

- **贴 option 就出图**：左边贴一段完整的 **ECharts option**（`title` / `xAxis` / `yAxis` / `series` / `dataset` 都认），右边立刻按这份配置渲染，支持折线、柱状、饼图、散点、雷达、树图等全部 ECharts 图表类型。不用记 API，从官方示例里复制一段 JSON 就能看效果。
- **只想看数据也行**：贴一组数字（`[820, 932, 901]`）、带名字的对象数组（`[{ "name": "1月", "value": 820 }]`）、`{"一月": 820, "二月": 932}` 这样的字典，或者散点用的 `[[x, y]]`，自动判形状并挑一个合适的类型；也可以在工具栏里换成折线 / 柱状 / 面积 / 饼图 / 散点。是完整 option 时下拉也能接着改：**自动**就听 JSON 里的 `series.type`，选了折线 / 柱状 / 面积 / 饼图 / 散点就按你选的画（前三者只换 `series.type`，饼图用类目名 + 首条系列重拼），不会改完类型只剩一片空白。
- **接口返回不用手工剥**：很多后台把图配置塞在业务 key 里、而且还是个字符串——`{"monthly_trend":{"echart_option":"{…}","table_data":null,"biz_data":{}}}` 直接贴进来就行。按 `echart_option` / `chartOption` / `chart_config` / `option` / `data` / `result` 这些键名加上内容判断往下找，最多剥三层，二次编码（字符串里还是 JSON 字符串）也解；提示条会写明「已自动解析 monthly_trend.echart_option」，不会悄悄把你贴的东西换掉。
- **一份 JSON 里有多个图 / 一次贴多份 JSON**：一个返回里带好几个图（`{"a":{"echart_option":…},"b":{…}}`、`{"charts":[option, option]}`、同一层的 `option1` / `option2`）时，工具栏会多出一个「图表」下拉，按标题列出来，点一下换一张；一行一个 JSON（NDJSON）或首尾相接的 `{…}{…}` 也能切开，路径标成 `#1…` / `#2…`，而一行一个数字则合并成一条曲线。
- **任务列表式的导出也能一张张挑出来**：顶层是数组、每条任务的某个字段又是一段序列化 JSON、展开后才是「业务键 → `echart_option` / `table_data` / `biz_data`」——这种套了六层、中间还夹着几千行表格的数据，图照样挖得出来（路径形如 `[0].payload.<业务键>.echart_option`，为 `null` 的不占位）。遍历会跳过纯数据行、预算随输入大小放大，所以「前面一大坨表格、图在后面」也压不垮；真遇到大到扫不完的输入，状态条会写明「只扫描了前面一部分」，不假装就这几张图。
- **先看整体，再放大看细节**：画布装不下面板时自动按「适应」缩小（装得下就 100%），工具栏有 `−` `适应` `比例` `+`：按 1.25 倍增减、点比例回 1:1、点适应回到整图；缩放只影响显示，导出与转换永远是原始像素。图片 Base64 页的预览用同一套控件，等比缩放不拉伸。
- **预览 1:1，不拉伸**：画布严格按输入框里的像素画，不做任何 CSS 缩放（所见即导出）；比面板宽时容器横向滚动，左侧也滚得到——之前居中布局会把画布的左半截顶出可视区，滚不回去。
- **宽高就是你定的像素**：默认 **宽 700 × 高 400**（横版，和 echarts-node-export-server 的默认一致），改一下输入框（80–4096）预览和导出一起变，所见即所得；越界会夹到边界并把输入框改成实际用的值，同时说明原因。改乱了点「重置宽高」一键回到 700 × 400。
- **像素比决定导出的清晰度**：工具栏「像素比」可选 **1x / 2x / 3x**，就是渲染时的 `devicePixelRatio`——1x 出输入框的宽高，2x / 3x 出 1.4 万、2.1 万像素级的更大位图，贴进文档、做成打印稿放大也不糊。每档后面直接标出这一档实际导出多少像素（`2x · 1400 × 800`），导出按钮的提示里也带着；文件名会加 `@2x` / `@3x` 后缀，一眼看出是几倍图。像素总量超过 2400 万（比如 4096 × 4096 选 3x）会自动降档，免得把宿主画布撑爆。
- **导出 PNG / SVG**：PNG 按「宽高 × 像素比」出图，走的是单独起的临时实例（`devicePixelRatio` 就是所选倍率、`animation: false`），所以导出结果和画布上的缩放状态无关；SVG 走 ECharts 的 `renderToSVGString()` 出矢量文本。两者都能存成文件——DBX 里走宿主的保存通道，直接打开 `index.html` 时回退浏览器下载。出图**不跟界面主题走**：界面是暗色时也照样按 ECharts 默认（浅色）配色 + 白底出图，预览和导出永远是同一张——图是要拿去贴到别处的，换了底色在那边就不好看了。
- **放大查看**：点「放大查看」（或双击画布）把整张图铺到全屏灯箱里看，滚轮往光标处缩放、双击切 1:1 与适应、`+` `−` `0` `1` 快捷键、`Esc` 关闭。灯箱里的图同样按所选像素比渲染，放大到 300% 也不糊。图片 Base64 页的预览共用同一个灯箱。
- **画不出来就说清楚**：JSON 语法错、形状不认识、点太多（单系列 2 万 / 总计 5 万）、系列太多（30）、引擎没加载起来，各有各的提示，不会给你一张空白图。
- 图表引擎（ECharts 6.1.0）**随包离线**，只有进这一页才加载解析，首屏不为它付费；引擎不靠外链脚本，而是以惰性文本随页面一起走、进页时才包成 `blob:` 地址执行，宿主沙箱的 CSP 再严也拦不住；离开页面立即释放 canvas 与实例。

## 二维码转换

- **批量进、批量出**：一行一条，一列链接、单号或任意短文本按一下就是一片码，卡片从上到下编号，空行不会生成空码。把拆分切成**整段一个**，换行就留在同一个码里（通讯地址、JSON 片段、多行备注都行），只去掉首尾空行。
- **码本身由参数决定**：尺寸（128–1024 px，默认 256）、边距（0–8 个模块）、纠错级别（L / M / Q / H）、前景色与背景色——取色器点一下或直接填 `#rrggbb`。前景和背景太接近会提前提示，而不是丢给你一个谁都扫不出来的码。
- **中心图标，纠错级别跟着调**：选一张图片，先归一化成 256 px 的 PNG，再垫一层圆角白底画在正中间；纠错会**自动跳到 H**，因为中心被挖掉一块还能解出来的就这一档（L / M / Q 都解不出来）。手动调回去，提示条会写明「可能扫不出来」。
- **PNG 还是 SVG**：PNG 拿来发，SVG 拿去印——每一行连续的深色模块会并成一条路径线，200 个码也不会把 DOM 压垮。单张导出的**格式、尺寸、文件名当场定**（面板里选 PNG / SVG、256 / 512 / 1024 或手填 128–1024、文件名随手改，回车即存，下次还记着这次的选择），文本单独复制，**复制图片**走 `ClipboardItem` 直接把图放进剪贴板；**全部导出**把整批拼成一张接近正方形的 `qr-codes.png`，而不是弹 200 次保存框。
- **双击放大看细节**：卡片上的码双击就进灯箱——整屏看、滚轮往光标处缩放、双击在「适应」和 1:1 之间切、`Esc` 或点空白退出。灯箱里那张是按 1024 重新矢量画的，不是把卡片上的小图拉大，放到 147% 边角还是硬的；标题栏写「内容首行 · 1024 × 1024」，一眼知道在放大哪一张。这套灯箱和图片页共用。
- **可折叠，还认得来路**：卡片能收成「序号 + 一行预览」（`+` / `−`），点卡片或点它的序号，光标就跳回生成它的那一行——长列表两个方向都好找。
- **图片解回文本**：切到第二个模式，拖进图片、粘贴截图或者一次给一批文件，逐张解码（每张先缩到长边 1600，解完立刻释放），结果列表带复制按钮。单个和批量都认，原本带换行的内容解出来也带换行。
- 两个引擎（qrcode-generator、jsQR）都**随包离线**，以惰性文本的形式跟着页面走、进页时才包成 `blob:` 地址执行；解码引擎（251 KB）只在你真的切到那个模式时才加载。文本按 UTF-8 编码，中文内容解出来不会变成乱码。

## 工作流

- **每个功能页都能导入文件，页面不跟着跑**：在哪个页面，导进来的文件就归哪个页面处理。整个窗口都是投放区（拖进来时浮一层提示，蒙层里直接写着这一页的体积上限），输入区的「导入文件」按钮走的是同一条通道。在「格式转换」拖 `.json` / `.yaml` / `.xml` / `.toml` / `.ini` / `.env` / `.log` / `.md` / `.csv` / `.tsv` 会按扩展名设好源格式并直接算出结果，扩展名不认识（`.dat` / `.out` / `.resp` 这类导出文件）也照收，读进来按内容嗅探；「JSON 对比」两栏各有自己的「导入左侧 / 导入右侧」，拖进来则先填还空着的那一侧；SQL / 转义 / 字节 / 时间 / 图表 / 代码生成 / 查询校验 各吃各的文本，导入后立刻按本页规则出结果；二维码转换生成时吃文本、解码时吃图片。图片和表格文件不会被硬读成乱码：拖到文本页只提示去「图片 Base64」或「表格转 JSON」，**不会替你换页**。
- **导入的边界写在明处**：文本单文件 16 MB（图片 10 MB、表格 20 MB），超了在入口就拦下，提示里给出实际大小与上限，不会先把文件读进内存；读出来发现是二进制（含 NUL / 大量乱码）也会拒绝并说明。导入完提示条里常驻「文件名 · 体积」，超过 2 M 字符的文本只载入、不自动转换（避免拖入瞬间把宿主卡住），点「执行转换」再算。
- **一次拖多个表格**：最多 10 个文件，按当前选项解析后合并成**一个以文件名为键的 JSON**（`{"a.csv": [...], "b.csv": [...]}`），重名自动变成 `a (2).csv`。预览区显示第一个文件，复制 / 导出针对合并结果（`batch-2.json`）。
- 页面内的投放区与全局入口共用一套判定：图片页的拖拽区先接住图片（页面级处理器先跑，全局处理器看到事件已被处理就让开），拖到窗口别处也只会交给当前这一页，结果一致。
- 拖放走的是宿主通道：DBX 窗口是 Tauri / WebView，系统文件拖放由宿主先接管，页面里收不到原生 `drop`；插件用 `dbxPlugin.fileTransfer.onDrop` 拿句柄（`handleId`）再按 256 KB 分片读回内容，蒙层跟 `onDragState` 走。直接打开 `index.html` 预览时自动退回浏览器事件，两条路都能拖。

## 通用

- **国际化**——14 种语言：zh-CN、zh-TW、en、ja、ko、es、id、it、pl、pt、ru、th、tr、az。切换器里列出前三种，其余随宿主 locale 自动匹配；十二个页面（格式转换、对比、SQL、表格、图片、代码生成、查询校验、转义工具、字节转换、时间转换、图表、二维码）的文案都已覆盖全部 14 种，连 20 条 Schema 校验错误也有译文，缺一条会退回英文而不是中文。
- **主题适配**——跟随 DBX 宿主主题与 shadcn/ui 设计令牌，宿主只下发主题信息（不写 `data-dbx-theme`）或自定义调色板同样生效。首屏按宿主主题直接落定、不闪白底，明暗切换有 300 ms 整页过渡，`prefers-reduced-motion` 下自动关掉。唯一的例外是「JSON 转图表」画出来的图：它是产物，固定浅色配色 + 白底，不跟着变暗。
- **导航布局**——顶栏右上角的按钮让导航在「顶部」和「左侧」之间切换，默认顶部。切到左侧后十一个入口竖排成一列（13rem），内容区自动让出同样的宽度；「格式转换」这一组也排在这个列的最上面，下拉在栏内展开、把下面的入口往下推，不会盖住谁。一列放得下全部入口，所以不会出现「更多」。选择会记住：优先宿主 `dbxPlugin.storage`，没有该能力时退回浏览器 `localStorage`、再退回 `window.name`（`dbx-plugin dev` 的沙箱里只有它管用），重开还是上次的样子。
- **剪贴板**——通过 DBX Host API 一键复制，没有宿主时走浏览器降级方案。
- **离线**——无后端、无 CDN、无遥测；CodeMirror、YAML 库与 ECharts（Apache-2.0，`ui/vendor/echarts/` 连同 LICENSE）都打在包里，跑起来一次网络请求都没有。
